# Agentic Delivery Framework

Как команды поставляют софт с ИИ-агентами: модель, конвейер, спека, обвязка, Andon, контроль, метрики, ритм и внедрение по размеру компании.

## Что здесь

- `index.html` — интерактивный документ на одной странице без сборки. Откройте файл в браузере.
- `research/` — пять файлов с заметками ресерча (2025–2026): формирование и обвязка, управление и метрики, стартапы, крупные компании, модели зрелости.

## Как читать

Разделы идут по логике фреймворка: Модель → Конвейер → Спека → Обвязка → Andon → Контроль → Метрики → Ритм → Внедрение → Стартап-кит → Основания.

Каждое правило помечено одним из трёх способов:

- **есть источник** — подтверждено внешними данными;
- **гипотеза** — стартовое значение, его нужно калибровать на своих данных;
- **наше предложение** — вывод из ресерча, в источниках напрямую нет.

## Что стоит знать о данных

Часть источников читалась по выдержкам поиска, а не в оригинале. Цифры компаний — их собственные заявления без независимого аудита. Файлы в `research/` — рабочие заметки, а не вычитанные тексты.
