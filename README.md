# Agentic Delivery Framework

Фреймворк работы с ИИ-агентами при разработке ИТ-продуктов любого размера. Главное правило: ИИ — инструмент, решает и отвечает человек.

## Что здесь

- `index.html` — интерактивный документ на одной странице без сборки. Откройте файл в браузере.
- `CLAUDE.md` — правила работы над фреймворком и устройство `index.html`.
- `research/` — файлы с заметками ресерча (2025–2026): формирование и обвязка, управление и метрики, стартапы, крупные компании, модели зрелости, конспект AWS AI-DLC, данные о том, ускоряет ли ИИ разработку.

## Как читать

Восемь блоков, каждый — отдельная вкладка:

1. **Основа** — цель, главное правило, границы, словарь, данные и гипотезы.
2. **Принципы** — девять принципов с опорой на PMI, Lean, Agile, DevOps и документ Google.
3. **Роли** — восемь ролей, было → стало, матрица решений, агент без ответственности.
4. **Цикл** — девять стадий, семь ворот, петли возврата, приём, спека, выпуск и откат.
5. **Поток** — узкое место, лимиты с расчётом по Ферми, остановка агента, ритм без спринтов.
6. **Качество** — пять слоёв проверок, обвязка, классы риска, контроли безопасности, аудит.
7. **Измерение** — дерево метрик, анти-метрики, ритм встреч, ускоряет ли ИИ на самом деле.
8. **Внедрение** — подгонка по размеру компании, шесть фаз перехода, стартап-кит.

Каждое правило помечено одним из трёх способов:

- **есть источник** — подтверждено внешними данными;
- **гипотеза** — стартовое значение, его нужно калибровать на своих данных;
- **наше предложение** — вывод из ресерча, в источниках напрямую нет.

## Что стоит знать о данных

Часть источников читалась по выдержкам поиска, а не в оригинале. Цифры компаний — их собственные заявления без независимого аудита. Файлы в `research/` — рабочие заметки, а не вычитанные тексты.
